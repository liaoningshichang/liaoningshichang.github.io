云端同步（Supabase）

未配置（当前仅保存在本机浏览器）
首次配置 4 步
  1. 打开 supabase.com 注册 → New Project（区域选 Tokyo/Singapore）
  2. 左侧 SQL Editor 粘贴运行：
    create table sync_kv(key text primary key, value jsonb, updated_at timestamptz default now());
    alter table sync_kv enable row level security;
    create policy p on sync_kv for all using(true) with check(true);
  3. Settings → API Keys：复制 Project URL 和 publishable/anon key
  4. 粘贴到上方 → 点 测试并同步

⚠ 含 Key 的链接不要公开发布，私聊发给同事。
